# Training Model Integration Guide

## Overview

This guide explains how to integrate your Google Colab training code into this Django Fake News Detection project.

## Project Structure

```
django-starter/
├── train_model.py          ← **REPLACE THIS FILE** with your Colab code
├── a_detection/
│   ├── views.py           ← Uses the trained models for prediction
│   └── utils.py           ← Contains preprocess_text() function
├── model.joblib           ← Main classification model (generated by training)
├── vectorizer.joblib      ← TF-IDF vectorizer (generated by training)
├── explainer_model.joblib ← Explainer model (generated by training)
├── word2vec.model         ← Word2Vec model (generated by training)
├── fake.csv               ← Training dataset
└── true.csv               ← Training dataset
```

## Which File to Replace?

**Answer: Replace `train_model.py`**

This is the file that contains the model training logic. Your Google Colab code should replace the content of this file.

## Important Requirements for Your Colab Code

When adapting your Colab code to `train_model.py`, ensure it:

1. **Imports the preprocessing function** from the Django app:
   ```python
   from a_detection.utils import preprocess_text
   ```

2. **Saves the models with these exact names** in the Django project root:
   - `model.joblib` - Main Logistic Regression model (Word2Vec features)
   - `vectorizer.joblib` - TF-IDF vectorizer
   - `explainer_model.joblib` - Explainer Logistic Regression model (TF-IDF features)
   - `word2vec.model` - Word2Vec model (saved using `gensim.models.Word2Vec.save()`)

3. **Uses the same dataset files**:
   - `fake.csv` - Fake news dataset
   - `true.csv` - True news dataset

4. **Maintains the same preprocessing pipeline** that matches `a_detection/views.py`:
   - Uses `preprocess_text()` from `a_detection.utils`
   - Creates document vectors using Word2Vec
   - Uses TF-IDF for the explainer model

## How to Run the Training Script

### Option 1: Direct Python Execution (Recommended)

1. **Activate your virtual environment**:
   ```powershell
   cd D:\projects\FND
   .\venv\Scripts\Activate.ps1
   ```

2. **Navigate to the Django project directory**:
   ```powershell
   cd django-starter
   ```

3. **Run the training script**:
   ```powershell
   python train_model.py
   ```

### Option 2: Using Django Management Command

You can also create a Django management command (advanced), but direct execution is simpler.

### Prerequisites Before Running

1. **Ensure datasets are present**:
   - `fake.csv` in `django-starter/` directory
   - `true.csv` in `django-starter/` directory

2. **Install all dependencies**:
   ```powershell
   pip install -r requirements.txt
   ```

3. **NLTK data will be downloaded automatically** (if not present)

## How It Integrates with the Django App

After training, the models are automatically used by the Django application:

1. **Model Loading** (`a_detection/views.py` lines 28-38):
   - Models are loaded once when Django starts
   - Stored in module-level variables for efficient reuse

2. **Prediction Flow** (`a_detection/views.py` line 52-120):
   - User submits title and body via web interface
   - `predict_fake_news()` function:
     - Preprocesses input using `preprocess_text()`
     - Creates Word2Vec document vector
     - Predicts using `model.joblib`
     - Generates explanations using `explainer_model.joblib`
     - Calculates similarity using `word2vec.model`

3. **Files Used During Prediction**:
   - `model.joblib` - Main prediction
   - `word2vec.model` - Document vectorization
   - `vectorizer.joblib` - Keyword extraction
   - `explainer_model.joblib` - Feature importance

## Troubleshooting

### Error: "No module named 'a_detection'"
- **Solution**: Make sure you run the script from the `django-starter/` directory
- Or set PYTHONPATH: `set PYTHONPATH=D:\projects\FND\django-starter`

### Error: "FileNotFoundError: fake.csv"
- **Solution**: Ensure `fake.csv` and `true.csv` are in the `django-starter/` directory

### Models not updating in Django app
- **Solution**: Restart Django server after training: `python manage.py runserver`

### Import errors for sklearn/gensim
- **Solution**: Install requirements: `pip install -r requirements.txt`
